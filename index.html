Rich Menu Switcher ยังไม่เชื่อมต่อ

ระบบจัดการ Rich Menu แบบสลับแท็บ — LINE OA: TOP TEST 3

เชื่อมต่อ LINE Channel

หา token ได้ที่ developers.line.biz → Provider → Channel "TOP TEST 3" → แท็บ Messaging API → Channel access token (กด Issue)

💡 Free tier: server จะถูกรีเซ็ตเมื่อไม่มีคนใช้ — งานออกแบบระบบจะกู้คืนจากเบราว์เซอร์ให้อัตโนมัติ แต่ token แนะนำตั้งเป็น Environment Variable ชื่อ CHANNEL_ACCESS_TOKEN ใน Render Dashboard จะได้ไม่ต้องใส่ใหม่ทุกครั้ง

เครื่องมือ Channel

1 เลือกวิธีออกแบบปุ่ม

สลับแท็บ ลิงก์ ข้อความ ไม่กำหนด (รูปเฉยๆ)

2 ใส่รูป Rich Menu

📷 คลิกเพื่อเลือกรูป หรือลากรูปมาวางที่นี่ (แนะนำ 2500×1686 px — ระบบย่อ/ครอป + บีบอัดไม่เกิน 1MB ให้อัตโนมัติ)

3 แก้ไขปุ่ม

ปุ่มทั้งหมด
◀ X — ระยะจากขอบซ้าย
▲ Y — ระยะจากขอบบน
↔ กว้าง
↕ สูง

ยังไม่ได้เลือกปุ่ม — คลิกปุ่มบนรูป

4 Draft, ตั้งเวลา และเผยแพร่

💾 Draft ยังไม่ได้บันทึก

การเผยแพร่เป็นแบบ manual: ถึงเวลาเริ่ม campaign แล้วกด "เผยแพร่" เอง (LINE API ไม่มีระบบตั้งเวลาในตัว — ระบบจะเตือนถ้ายังไม่ถึงเวลาที่ตั้งไว้)
